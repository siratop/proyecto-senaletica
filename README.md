# 🚌 Proyecto SeñalEtica+ 

Sistema integral de gestión, telemetría GPS, reportes ciudadanos y publicidad para unidades de transporte público. 

## 🚀 Tecnologías y Herramientas Utilizadas
* **Backend:** Python 3.10+, Django 5.x
* **Base de Datos:** PostgreSQL 15+ (Entorno principal) / SQLite (Pruebas aisladas)
* **Gestión de Estáticos:** WhiteNoise
* **Frontend:** HTML5, CSS3, JavaScript puro (Carrusel dinámico y manejo de DOM)
* **Arquitectura Móvil:** Progressive Web App (PWA) con Service Workers y Manifest JSON (Instalable en Android/iOS/Desktop).
* **Control de Versiones:** Git y GitHub

## ⚙️ Requisitos Previos para el Equipo
Antes de descargar el código, cada desarrollador debe tener instalado en su PC:
1. **[Python 3.10 o superior](https://www.python.org/downloads/)** (Asegúrate de marcar "Add Python to PATH" al instalar).
2. **[Git](https://git-scm.com/)** (Para clonar el repositorio).
3. **[PostgreSQL y pgAdmin 4](https://www.enterprisedb.com/downloads/postgres-postgresql-downloads)** (Motor de base de datos).
4. **[Visual Studio Code](https://code.visualstudio.com/)** (Editor de código recomendado).
